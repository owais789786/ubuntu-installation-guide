VMware Workstation Pro 17 - Ubuntu 26.04 Installation Guide

Follow this guide to easily install Ubuntu.

Step 1: Create a New Virtual Machine

First, open VMware Workstation and start the process of creating a new virtual machine.

Open VMware and click on "Create a New Virtual Machine".

Select "Typical (recommended)" and click Next.

Select "Installer disc image file (iso)" and browse for your Ubuntu ISO file.

Note: If you see a "Cannot read this file" error here, don't worry, it happens sometimes. Just select your ISO file.

Select your Ubuntu ISO file (e.g., ubuntu-26.04.1-desktop-amd64.iso) and click Open.

Enter your Full name, User name, and Password. This will be your account in Ubuntu.

Click Next after filling in the details.

Set the Virtual Machine name (e.g., Ubuntu 64-bit) and location. Click Next.

Set disk capacity to 20 GB and select "Split virtual disk into multiple files". Click Next.

Review the settings and click Finish with "Power on this virtual machine after creation" checked.

Step 2: VM Boot and Initial Setup

Now your virtual machine will start and Ubuntu will boot.

Ubuntu 26.04 is booting. Please wait.

The boot process is running. (If it says SMBus Host Controller not enabled, it's normal and not a problem).

When the login screen appears, enter your password or click the login button.

Step 3: Ubuntu Installation Process

Configure the Ubuntu installer step-by-step.

Select your language (English recommended) and click Next.

Skip accessibility settings (Click Next).

Select keyboard layout (English). If prompted to detect, you can select "Yes" or "No".

Select "Use wired connection" to ensure internet connectivity. Click Next.

Select "Install Ubuntu". Click Next.

Select "Interactive installation". Click Next.

Select "Default selection" (Basic apps and web browser). Click Next.

Leave both proprietary software options unchecked (or check based on your needs). Click Next.

Select "Erase disk and install Ubuntu". (This will only erase your Virtual Machine's disk, not your actual computer). Click Next.

Select "No encryption". Click Next.

Enter your name, computer name, username, and password. (If you see a "Weak password" warning, that's fine, you can also use a strong password). Click Next.

Select your timezone (e.g., Lahore/Karachi, Pakistan). Click Next.

Review your settings and click the "Install" button.

Step 4: Installation Complete

Files will now start copying. This can take 10 to 15 minutes.

Ubuntu is copying files. Keep an eye on the progress bar.

Once installation is complete, the system will restart and the terminal will show "Welcome to Ubuntu 26.04.1 LTS!".

System services are starting. Please wait.

Congratulations! Your Ubuntu VM is ready. You can now use it.
