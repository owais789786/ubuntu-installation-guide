Ubuntu Desktop via USB

10 steps to install Ubuntu

Check each step when complete. Your progress is saved in this browser.

01

Prepare your PC and USB drive

Use a USB drive with at least 8 GB of storage. Keep your laptop plugged in during installation. Copy any important files off the USB first, because creating the installer will erase it.

  • • A stable internet connection
  • • At least 25 GB of free disk space recommended
  • • A backup of important files on another drive or in the cloud
02

Download the Ubuntu ISO

Visit the official Ubuntu website and download the latest Desktop LTS release. The filename usually ends in `.iso`. Let the download finish; there is no need to extract the file.

Download Ubuntu Desktop from the official site
03

Create a bootable USB drive

On Windows, download and open Rufus, select your USB drive, then choose the Ubuntu ISO under Boot selection. For most modern PCs, use `GPT` for Partition scheme and `UEFI` for Target system. Click `Start` and confirm that the USB drive can be erased.

If prompted for a writing mode, keep the recommended option. Do not remove the USB drive until the process is complete.

Rufus official website
04

Boot your computer from the USB

Shut down your computer and plug in the bootable USB. As it powers on, repeatedly press the Boot Menu key. Common keys include `F12`, `F10`, `Esc`, and `F2`; the key varies by manufacturer. Select `UEFI: USB` from the menu.

If Windows starts instead, restart and try another boot key, or check your computer manufacturer's website for the key for your model.

05

Open the Ubuntu installer

Ubuntu will start after the boot menu. On the welcome screen, choose `Try or Install Ubuntu`, then select `Install Ubuntu`. If the desktop appears first, double-click the `Install Ubuntu` icon.

If the screen looks blank or frozen, wait a few minutes. If the issue continues, restart and select the USB drive from the boot menu again.

06

Choose your language, keyboard, and network

Choose your preferred language and keyboard layout, then test the layout. Connecting to Wi-Fi or Ethernet is helpful for downloading updates and drivers. If you do not have internet access, you can usually continue and connect later.

The order and wording of screens may vary slightly depending on the installer version.

07

Choose apps and updates

The `Normal` option includes common desktop apps; `Minimal` includes only the essentials. If you are online, the installer can download updates. Select the option for third-party graphics or Wi-Fi drivers and media formats only if you want to install them.

08

Choose the installation type and disk

Choose `Erase disk and install Ubuntu` only if you want Ubuntu to replace everything on the selected disk. This can permanently delete the data currently stored there.

Want to dual boot? To keep Windows, choose `Install Ubuntu alongside Windows` if that option is available. If it is not available, you are unsure about the partitions, or you have not backed up your data, stop here.

`Something else` is for manual partitioning; use it only if you understand disk partitions. Before confirming, double-check the selected disk's name and capacity.

09

Set your location and user account

Choose your time zone or location. Then enter your name, computer name, username, and a strong password. Keep the password somewhere secure; you will need it to sign in and manage your system.

Review the summary on screen and verify your disk and installation choices one last time.

10

Install, restart, and remove the USB

Click `Install` or `Install Now`. Review the final disk-change confirmation carefully before approving it. Do not turn off your computer while installation is running; it may take some time.

When `Restart Now` appears, restart the computer. Remove the USB drive when prompted, then press Enter. Sign in to Ubuntu with your password.

After installation

Update your system

Connect to the internet once your desktop loads. Open Software Updater to install updates, or run this command in Terminal:

sudo apt update && sudo apt upgrade

It is normal for password characters not to appear in Terminal. Type your password and press Enter.
